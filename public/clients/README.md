# Client logos

Put client logos here, then add them to `src/content/clients.ts`.

- **Format:** SVG preferred, otherwise transparent PNG
- **Size:** around 400 px wide; the site scales them down
- **Colour:** single-colour / white versions read best on the dark background

Only add companies you have genuinely worked with. While
`src/content/clients.ts` is empty the site shows neutral "Add client logo"
tiles that do not imply any real relationship.
